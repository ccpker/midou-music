# 酷狗扫码登录 — 最小单元修复 (2026-07-28 15:17)

## 问题

KugouLogin 组件切走再回来又是二维码，token 不保存。

## 根因

1. **`kugou_login.rs` 是屎山** — 混杂了签名函数、HTTP helper、PNG 生成、Tauri 命令，全揉在一个文件里
2. **符号引用错误** — `debug_log::info(kugou_login, ...)` 中 `kugou_login` 没引号，compile error → 运行的是旧二进制
3. **HMR 不触发重新编译** — 前端热更新不重新编译 Rust 后端，前端代码和实际运行的二进制脱节

## 修复方案

### 拆成 3 个独立最小单元

| 单元 | 文件 | 行数 | 职责 | 可独立测试 |
|------|------|------|------|-----------|
| `qr` | `src/qr.rs` | ~120 | 纯 HTTP — fetch_qr / poll_qr / 签名 | `cargo test qr::test` |
| `kugou_login` | `commands/kugou_login.rs` | ~100 | Tauri 命令薄包装 — 每个 < 15 行 | 需 Tauri 环境 |
| `db` | `db.rs` | 已有 | save/load/delete | `cargo test db::` |

### 关键改动

- `qr.rs`: 零副作用纯函数，输入 reqwest::Client，输出 struct，不碰 AppState/DB
- `kugou_login.rs`: 完全重写，删除所有签名/HTTP/PNG 逻辑，只做 3 步：调 qr:: → 写 DB → 写内存
- `kugou_save_qr_token` 中 DB 写入 + 内存更新都加了 `debug_log` 日志
- KugouLogin.tsx: 首次打开先调 `kugou_auth_status`，已登录就不拉二维码

## 验证方法

1. 编译: `cargo check` ✅ (0 errors, 5 warnings)
2. 启动后打开酷狗登录 → 应自动显示「已登录」或无登录则弹二维码
3. 扫码成功 → 切换到搜索 → 切回登录 → 应显示「已登录」不再弹二维码
4. 关掉程序重开 → 打开酷狗登录 → 应显示「已登录」
