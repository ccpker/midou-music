## 歌词架构

```
PlayerPanel.tsx  🎤 点击
  → setLyricsOpen(true)
    → LyricsPanel.tsx (isOpen=true)
      → invoke("get_lyrics", { trackName, artistName })
        → Rust → LRCLIB API
          → 返回 synced_lyrics / plain_lyrics
      → parseLrc() → LrcLine[]
      → 500ms 轮询 position → findActiveLine() → 高亮 + 滚动
  → 🎤 再点 / X → setLyricsOpen(false)
```

## LRCLIB API

- 精确匹配：`GET https://lrclib.net/api/get?track_name=xxx&artist_name=xxx`
- 搜索兜底：`GET https://lrclib.net/api/search?q=xxx` → 取第一条 → 再调详情
- 实测可用（周杰伦 七里香 返回完整 LRC）

## LRC 解析

- 支持多时间标签 `[01:23.45][02:34.56]text`
- 毫秒级精度
- 当前位置匹配（<= positionMs 的最后一行）
