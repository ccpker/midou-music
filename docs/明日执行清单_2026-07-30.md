## 🔴 P0: 核心阻断 — 设备注册 (register_dev)

> **发现于 2026-07-31 源码拆解**

这是播放不通的根因。酷狗服务器不认识我们的设备 → 每次请求都是"陌生设备" → 20028 频繁触发。

KuGouMusicApi 启动时调一次 register_dev → 拿 dfid → 后续请求带 dfid → 「嗯这是正常设备」 → SSA 极少触发。

**register_dev 需要** (已完整逆向):
- RSA + AES 加密设备信息 (register_dev.js)
- 模拟 20+ 传感器数据（品牌Xiaomi/型号marble/陀螺仪/加速度/光线/步数...）
- 端点: `userservice.kugou.com/risk/v2/r_register_dev`

**依赖链**:
```
register_dev → dfid → 后续请求带 dfid → 建立信任
  → SSA 触发概率 ↓↓
  → 即使 SSA → generate_simulate(sid/edt) → 滑块 → verify
  → 播放 URL ✅
```

**做法**:
- [ ] 实现 `register_dev_request` (Rust: RSA 公钥加密 + AES-128-CBC, 20种传感器常量)
- [ ] 启动时自动调用一次
- [ ] 拿到的 dfid 写入 store 持久化
- [ ] 后续 kugou_api_req 带 dfid + kg-* 头

### 1.5 同时修的: calculateMid 算法

**现状**: `mid = md5(dfid)`  ← 错的  
**正确**: `KUGOU_API_MID = UUID → MD5 → hex视为大整数 → 十进制`

这是 server.js 自动注入的，我们缺这个导致歌单 20017。

**做法**:
- [ ] `calculate_mid_decimal(guid)` — MD5 hex → BigUint → 十进制字符串
- [ ] kugou_api_req 带 `KUGOU_API_MID`

## 🟡 P1: SSA 全链路

register_dev 会降低 SSA 频率，但不能完全消除。SSA 全链路还是要跑通:

1. 20028 返回 → 捕获 `ssa-code` header
2. sid/edt 生成 (generate_simulate 行为指纹 + AES+RSA) → ssa.rs 已有实现

4. RiskVerifyModal.tsx → 腾讯滑块 (需验证 Tauri WebView 中 CDN 加载)
5. verify_user_info → 成功
6. 重新请求 v5 → 拿 URL

**做法**:
