# 酷狗播放修复 — 2026-07-31 16:45~17:05

## 核心 Bug（根因）

**`song_url` 读错 JSON 字段层级** — 我们读了 `v["data"]["url"]`，但 `song_url.js` 走 v5/url 返回的是酷狗原始响应：

```json
{"url": ["http://...", "http://..."], "status": 1, ...}
```

URL 在**顶层数组**，不在 `data` 下。Rust 代码永远取不到 URL，返回 "no url in:"。

## MoeKoeMusic 对比结论

三个差异，但只有 #1 导致播放失败：
1. ~~dfid 缺失~~ — 加了有比没有好，但不是播放失败的根因（测试三种传法都能拿到 URL）
2. ~~设备指纹不全~~ — sidecar server.js auto-inject KUGOU_API_MID/GUID/DEV/MAC
3. ~~SSA 滑块~~ — 酷狗平台版权限制（status=2 fail=['buy']），不是我们代码 bug

**根因就是读错了字段层级。**
