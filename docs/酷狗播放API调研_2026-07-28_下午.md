# 酷狗播放 API 调研报告
**时间**: 2026-07-28 下午  
**目标**: 解决酷狗 `errcode=20006` 和 `errcode=0 但 url=null` 问题

---

## 结论速览

| 问题 | 根因 | 状态 |
|------|------|------|
| `errcode=20006 sign error`（kmr 无 mid 字段） | mid 字段缺失，签名不匹配 | ✅ 已修复 |
| `errcode=0 bitrate=128 url=null` | **版权/可用性限制**，非签名问题 | ⚠️ 无法绕过 |
| kmr 随机 dfid | kmr 不校验 dfid，errcode=0 | ✅ 不影响 |
| v6 概念版 `invalid appid` | mid=dfid_md5 无法通过服务端校验 | ⚠️ 需真实设备 |

## kmr v1 API 实测结果（关键发现）

**测试方法**: Node.js `http` 模块直接发 POST 请求

### 变量矩阵测试

| hash | mid 字段 | mid 值 | errcode | bitrate | url |
|------|----------|--------|---------|---------|-----|
| 16字符 | ✅ 有 | `"null"` | **0** | 128 | null |
| 32字符 | ✅ 有 | `"null"` | **0** | 128 | null |
| 16字符 | ❌ 无 | - | 20006 | - | - |
| 32字符 | ❌ 无 | - | 20006 | - | - |

### 关键结论

1. **签名机制完全正确** — `mid="null"` 字符串通过 kmr 签名验证
2. **`mid` 字段必须存在** — 即使 kmr 不校验 mid 内容，也必须有该字段
3. **url=null 是版权限制** — errcode=0 表示请求+签名正确，但服务器返回 url=null 是因为版权/可用性问题
4. **与 hash 无关** — 完整32字符hash测试后仍然 url=null

## v6 概念版 API 测试结果

| 参数组合 | 结果 |
|----------|------|
| 无签名无appid | `invalid appid` |
| URL加appid无签名 | `invalid sign` |
| URL加appid+签名 | `invalid clienttime` |

- v6 `clienttime` 需要**毫秒**（`Date.now()`），非秒
- v6 的 `tracker_param.key` 需要真实 `mid`（从 cookie 来的 `KUGOU_API_MID`）
- 使用随机 dfid/md5_hex(dfid) 作为 mid → `error_code=20006`

## kmr key 签名验证

Node.js 测试确认 kmr `key` 签名算法：

```javascript
const key = md5(appid + liteSignSalt + clientver + clienttime_ms)
// 例: md5('3116' + 'LnT6xpN3khm36zse0QzvmgTZ3waWdRSA' + '11440' + '1753764828000')
```

## kmr vs v6 vs v5 对比

| 特性 | kmr v1 | v6 概念版 | v5 CDN |
|------|--------|-----------|--------|
| host | kmr.service.kugou.com | tracker.kugou.com | trackercdn.kugou.com |
| 签名 | key = MD5(params) | MD5(body+params) | MD5(sorted params) |
| mid 处理 | 固定 `"null"` | 需真实 mid | 需 dfid+mid |
| dfid 处理 | 不校验 | 需真实 dfid | 需真实 dfid |
| 无登录 | ✅ 签名通过 | ❌ `invalid appid` | ❌ `20006` |
| 有登录 | ✅ 签名通过 | ✅ 签名+url通过 | ✅ 签名+url通过 |
| 版权限制 | url=null | url=null | errcode=20028 |

## Rust 代码改动（kugou.rs）

### kmr v1 主链路（替代原来 v6）
```rust
let clienttime_ms = SystemTime::now().duration_since(UNIX_EPOCH).unwrap().as_millis() as u64;
let kmr_key_sig = kmr_key(LITE_APPID, LITE_CLIENTVER, clienttime_ms);
// kmr mid 固定为 "null" 字符串（实测验证通过）
let kmr_mid = "null";
let kmr_body = serde_json::json!({
    "appid": LITE_APPID,
    "clienttime": clienttime_ms,    // ✅ 毫秒
    "clientver": LITE_CLIENTVER,
    "data": [{ "hash": hash_lc, "audio_id": 0 }],
    "dfid": dfid,
    "mid": kmr_mid,                // ✅ "null" 字符串
    "key": kmr_key_sig
});
```

### 链路2：v6 概念版兜底
- 保留原有 v6 接口
- clienttime 改为秒（毫秒/1000）
- v6 mid 有 auth.kugou_api_mid → 用它；无则用 md5_hex(dfid)

### 新增函数
- `kmr_key()`: kmr key 签名（替代原来 android_sign 用于 kmr）
- `v6_body_sign()`: v6 body 签名（重命名自 android_sign）
- 修复 `generate_dfid()`: 补全缺失的右括号
