# 歌单/最近/收藏 API 修复 — 2026-07-30 09:17

## 根因

`playlists` 原来用 `gateway.kugou.com/v1/playlist/list`，KuGouMusicApi 源码实际用的是 **cloudlist 服务**。gateway 端点不存在/权限不够，所以返回空。

## 修复内容

### 1. 歌单 (playlists)
- **旧**: `GET gateway.kugou.com/v1/playlist/list`
- **新**: `POST cloudlist.service.kugou.com/v7/get_all_list` — 与 KuGouMusicApi `user_playlist.js` 完全一致
- 响应结构: `status=1` 成功，`data.info[]` 是歌单数组
- 参数: `{userid, token, total_ver:979, type:2, page:1, pagesize:30}` + query `plat=1,userid,token`

### 2. 最近播放 (recent_plays) — 新增
- 端点: `POST gateway.kugou.com/playhistory/v1/get_songs`
- 参数: `{token, userid, source_classify:"app", to_subdivide_sr:1}`
- 响应: `error_code=0` → `data.list[]`

### 3. 用户歌曲/收藏 (user_songs) — 新增
- 端点: `GET gateway.kugou.com/youth/v1/get_user_song_public`
- 参数: `filter_video=0, type=0, userid, pagesize=30, page, is_filter=0`
- **不需要 token**（公开接口），只要 userid 即可获取用户公开收藏
- 响应: `error_code=0` → `data.list[]`
