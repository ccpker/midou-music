## 一、问题诊断：v2 当前实现错在哪？

### v2 现状（错的）

| 环节 | v2 实现 | 实际情况 |
|------|---------|----------|
| **搜索** | `songsearch.kugou.com/song_search_v2`（公开匿名 API） | 返回 errcode=152 → 需登录 |
| **播放** | `www.kugou.com/yy/index.php?r=play/getdata` | errcode=20010 → 版权限制 |
| **概念版盐值** | 写在常量里但未用 | 正确 |

**结论**：v2 kugou.rs 用错了端点，没有真正用到"概念版"API。

### v1 已验证的实现（对的）

**端点（走 gateway.kugou.com）**：

| 功能 | 端点 | x-router | 鉴权 |
|------|------|----------|------|
| 搜索 | `GET /v3/search/song` | `complexsearch.kugou.com` | Android 签名 |
| **播放** | `POST /v2/get_res_privilege/lite` | `media.store.kugou.com` | Android 签名 + body |
| 歌单 | `POST /v7/get_all_list` | `cloudlist.service.kugou.com` | 需登录 token |
| 歌词 | `lyrics.kugou.com/search` + `/download` | - | 无（HTTP） |

**配置参数**（v1 已验证）：
- appid = `3116`（概念版）
- clientver = `11440`（概念版）
- 签名盐 = `LnT6xpN3khm36zse0QzvmgTZ3waWdRSA`（**概念版**，不是标准版）
- dfid 默认 = `2-a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6`（兜底）
- mid = `MD5(UUID) → hex → u128 → decimal`

**签名算法**：
```
MD5(salt + sorted(k=v,...) + body + salt)
```

## 三、关键 API 完整规范（从 v1 代码提炼）

### 3.1 搜索（v3/search/song）

```python
GET https://gateway.kugou.com/v3/search/song
Headers:
  x-router: complexsearch.kugou.com
  User-Agent: Mozilla/5.0 (Linux; Android 13; 2304FPN6DC) ...

Query:
  keyword=周杰伦
  page=1
  pagesize=20
  platform=AndroidFilter
  albumhide=0
  iscorrection=1
  nocollect=0
  dfid=<dfid>
  mid=<mid>
  uuid=<uuid>
  appid=3116
  clientver=11440
  clienttime=<unix_secs>
  signature=<md5_hex>
```

### 3.2 播放（v2/get_res_privilege/lite）

```python
POST https://gateway.kugou.com/v2/get_res_privilege/lite
Headers:
  x-router: media.store.kugou.com
  User-Agent: Mozilla/5.0 (Linux; Android 13; 2304FPN6DC) ...
  Content-Type: application/json

Query（签名参数）：
  appid=3116
  clientver=11440
  clienttime=<unix_secs>
  dfid=<dfid>
  mid=<mid>
  uuid=<uuid>
  signature=<md5_hex>

Body（JSON，参与签名）：
{
  "appid": 3116,
  "area_code": 1,
  "behavior": "play",
  "clientver": 11440,
  "need_hash_offset": 1,
  "relate": 1,
  "support_verify": 1,
  "resource": [{
    "type": "audio",
    "page_id": 0,
    "hash": "<FileHash>",
    "album_id": "<AlbumID>"
  }],
  "qualities": ["128", "320", "flac", "high", "viper_atmos", "viper_tape", "viper_clear", "super", "multitrack"]
}

响应取 max bitrate：
  data[0].relate_audio[max_by(bitrate)].url[0]
```

### 3.3 歌词（lyrics.kugou.com）

```python
Step1: GET http://lyrics.kugou.com/search
  ?ver=1&man=yes&client=pc
  &keyword=<歌名>
  &duration=<毫秒>
  &hash=<FileHash>

返回 → candidates[0].{id, accesskey}

Step2: GET http://lyrics.kugou.com/download
  ?ver=1&client=pc
  &id=<上步id>&accesskey=<上步accesskey>
  &fmt=lrc&charset=utf8

返回 LRC 文本（明文）
```

## 四、为什么 v1 能打通、v2 不行？

### 4.1 v1 的成功要素

| 要素 | v1 状态 |
|------|---------|
| 端点选择 | ✅ 走 gateway.kugou.com（不是 songsearch/yy） |
| 概念版配置 | ✅ appid=3116 / clientver=11440 / 概念版盐 |
| Android 签名 | ✅ 实现完整 |
| 登录体系 | ✅ 已实现（虽然部分歌曲需登录） |

### 4.2 v2 失败原因

1. **选错端点**：`songsearch.kugou.com` 公开接口要求 token
2. **复制旧代码**：把 v1 的早期错误版本（songsearch）搬到 v2，没用最终版本
3. **概念版参数未启用**：常量声明了概念版盐，但 search/play 调用没用到
