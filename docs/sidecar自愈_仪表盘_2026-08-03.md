# 酷狗 sidecar 自愈 + 仪表盘（2026-08-03）

## 改动

### 1. 插头自愈（`kugou_sidecar.rs`）
- 新增 `sidecar_get()` — 所有 HTTP 请求统一入口
- 每次请求前先 `health_check()` 探活
- 死了 → kill + spawn + wait_ready → 重试（≤3s）
- `health_check()` 改为 `pub`，供仪表盘调用
- 新增 `restart_sidecar()` — kill kill + spawn + wait

### 2. 仪表盘（`src/components/SidecarPanel.tsx`）
- 挂在侧边栏底部
- 每 10 秒自动探活
- 状态灯：🟢在线 / 🔴离线 / 🟡检测中
- 显示上次检测时间
- 🔄 按钮可手动重启引擎

### 3. Rust 命令层（`lib.rs`）
- 新增 `sidecar_health` — 返回 `{alive: bool}`
- 新增 `sidecar_restart` — 重启 sidecar

### 4. 前端集成（`Sidebar.tsx`）
- 导入 SidecarPanel
- 在底部设置按钮上方渲染
