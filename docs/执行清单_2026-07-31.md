## 架构决策（2026-07-31）

**酷狗全链路不再自建 Rust 实现。** 放弃 kugou.rs（900行签名）、ssa.rs（RSA/AES加密）、register_dev.rs（设备注册）、qr.rs（自包含登录）。

改为：**KuGouMusicApi 作为 Tauri sidecar**（Node 子进程，localhost:6521），登录/搜索/歌单/播放/SSA/设备注册 全部走 sidecar。Rust 端只做 HTTP 代理 + 类型转换。

**酷我**保留 Rust 原生（零登录即可用）。
