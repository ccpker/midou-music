## 三、07-24 重大突破详情

### 酷狗扫码登录 Rust 自建

**问题**：依赖 `node app.js`（Node 代理进程），关终端就死。

**解决**：把 KuGouMusicApi 的核心逻辑翻译成 Rust：
- `sign_web()`：MD5(盐 + 排序k=v + 盐)
- 直连 `https://login-user.kugou.com`（HTTPS + reqwest）
- 本地生成二维码 PNG（`qrcode` + `image` crate）
- `qrcode_key` → 二维码 base64 → 前端渲染

**关键文件**：`src-tauri/src/commands/kugou_login.rs`

**签名算法**：
```
盐 = "NVPh5oo715z5DIWAeQlhMDsWXXQV4hwt"
默认参数: dfid, mid=md5(dfid), uuid=md5(dfid+mid), appid=1005, clientver=11309
签名输入 = 盐 + k1=v1&k2=v2&... + 盐 → MD5
```

**编译踩坑**：
- `qrcode` 默认 features 引入 svg → 必须 `default-features = false, features = ["image"]`
- `code[(x,y)]` 返回 `Color` enum → 判断 `!= Color::Light`

### 验证流程
1. 蓝色诊断按钮 → `kugou_qr_key` → `key=8c79cb7f... img_len=2822`
2. 红色扫码按钮 → 弹窗显示二维码（base64 PNG）
3. 酷狗 APP 扫码 → status=4 → token 保存 → 弹窗消失
