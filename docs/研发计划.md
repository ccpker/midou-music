## 四、已探明的技术细节（备忘）

### 酷我车载API
- 端点：`mobi.kuwo.cn/mobi.s?f=web&source=kwplayer_ar_5.0.0.0`
- 搜索：`/api/www/search/searchMusicBykeyWord`
- 播放：`/api/www/music/playUrl`
- 零Cookie零登录，VIP全通
- 参数：`httpsStatus=1`、`type=convert_url3`、`br=2000kflac`
- 直播歌版本(medley)混入问题→v6三级降级管线解决(100%命中)

### B站音频
- WBI签名：`w_rid` = MD5(参数排序 + key)，key 从 `nav` 接口获取
- 搜索：`api.bilibili.com/x/web-interface/wbi/search/type`
- 音频流：`api.bilibili.com/x/player/playurl` + `fnval=4048` → DASH
- 歌词：走LRCLIB（B站本身不带歌词）
- parse_title 歌手/歌名搞反的 bug 已修复

### 酷狗概念版
- 设备注册：RSA公钥加密 + AES加密 mid
- DFID：设备指纹平台生成(IMEI/deviceId硬编码为000...)
- 签名：`signature` = MD5(params + key)
- 搜索端点：`gateway.kugou.com/api/v3/search`
- 播放：search → songinfo → play/get_audio
- 登录：扫码(QR key→轮询→token→长期session) 或 密码

### LRCLIB歌词
- 精确：`lrclib.net/api/get?track_name=&artist_name=`
- 模糊兜底：`lrclib.net/api/search?q=`
- 中文流行歌命中率极高

### Tauri v2 歌词窗口速查
- 拖拽：`data-tauri-drag-region` 属性，空值=整个元素可拖
- 按钮放行：`data-tauri-drag-region="false"`
- 窗口控制：`appWindow.minimize()/toggleMaximize()/close()`
- 权限：capabilities/default.json 需 `allow-start-dragging`
- withGlobalTauri：默认 false，前端需显式 import
