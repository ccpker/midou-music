# SSA 验证调试 2026-07-31

## 需要用户操作

1. 启动 tauri dev → 重新扫码登录
2. 播放歌曲 → 弹出"安全验证" → 拖滑块
3. **失败后把日志文件发来**

## 日志位置

日志文件在 `%APPDATA%\Roaming\com.midou.music\logs\` 下的最新 `.log` 文件，或者项目目录下的 `debug.log`。

需要看的关键行：
- `[ssa_verify] url=` — 看请求 URL 和参数
- `[ssa_verify] body=` — 看请求体
- `[ssa_verify] raw resp=` — 看服务器返回的原始内容

有了这些就能精确知道错在哪。

## 已验证的修复（本轮）

- `get_verify_info` sid/edt 传空字符串（对齐源码）
- RSA 加密回退为 raw modPow（cryptoRSAEncrypt 就是 raw）
- 加了详细请求/响应日志
