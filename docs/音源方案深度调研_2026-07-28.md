# 音源方案深度调研 — 2026-07-28

> 背景：酷狗播放地址（`/v5/url`、`/yy/index.php`）持续返回版权限制（20028/20010），自研签名登录方案遇阻，转向调研现有开源项目如何解决酷狗音源。

---

## 一、核心发现：酷狗音源的分层结构

酷狗实际上有两套并行接口：

| 接口层 | 入口 | 鉴权 | 播放地址 | 当前状态 |
|--------|------|------|----------|----------|
| **标准版** | `mobilecdn.kugou.com` | 可无登录搜索 | `/yy/index.php?r=play/getdata` | ⚠️ 版权限制（20010） |
| **概念版（Lite）** | `api.kugou.com` / `tkgou.tv` | **必须登录**（token） | `/v5/url` 等 | ⚠️ 需要账号体系 |
| **音乐库API（MakcRe）** | Node 服务代理 | 同上 | 同上 | ⚠️ `/v5/url` 仍失效 |

**结论**：酷狗的播放地址和账号体系深度绑定——**能拿到播放地址的前提是账号能拿到 token**，而 token 需要扫码/密码登录。这不是简单的签名算法能绕过的。

## 二、开源项目现状（2026-07）

### 2.1 EchoMusic（hoowhoami/EchoMusic）⭐ 最值得参考

**技术栈**：Electron 42 + Vue 3.5 + Rust NAPI（FFmpeg解码 + SoundTouch变速 + 实时频谱FFT）

**酷狗集成方式**：
- 使用酷狗**官方服务器直连**（"官方服务器直连，数据不经过第三方服务器"）
- 支持账号登录（扫码/手机/账号密码）+ **每日自动领取VIP**（概念版账号特性）
- 歌曲库与概念版同步
- 音质：SQ(flac)/HQ(320)/标准(128)

**关键洞察**：EchoMusic 并不自己逆向播放地址，而是**做概念版账号体系的客户端**——登录后走官方协议，获取VIP播放权限。概念版的"每日VIP领取"是官方给未付费用户的福利，EchoMusic 帮用户自动化了这个过程。

**插件系统**：支持自定义音源解析插件，`ctx.musicSources.register()` 可扩展新平台。

**最新活跃**：2026年仍维护，GitHub Actions 多平台自动构建。

---

### 2.2 MoeKoeMusic（iAJue/MoeKoeMusic）⭐ 独立客户端

**技术栈**：Electron + Vue 全家桶（自称）

**特性**：
- 酷狗账号登录（扫码/手机/账号密码）
- **每日自动领取VIP**（登录就是VIP）
- 主题色切换、启动问候语
- 酷狗概念版歌曲库

**局限**：
- 歌曲与概念版不完全一致（社区反馈"歌曲不全"）
- 账号登录需要验证（部分用户反馈登录窗口被拦截）

**最新状态**：2026-03-23 仍有博客介绍 v1.5.6 版本，百度网盘分发（限速）。

---

### 2.3 KuGouMusicApi（MakcRe）⚠️ Node 代理

**技术栈**：Node.js Express

**接口列表**（130+个）：
- 搜索、歌单、播放地址、歌词（KRC解码）、用户管理、云盘、评论

**关键问题**：设置 `platform=lite`（概念版），但 `/v5/url` 播放地址仍返回 `errcode:20028`（版权限制）。

**为什么**：MakcRe 的 `/v5/url` 底层调的还是酷狗接口，token 没有正确传、或者概念版接口本身在MakcRe的服务端环境下被风控。

**最新状态**：2026-06-05 Dockerfile 仍有更新，但核心播放问题未解决。

---

### 2.4 落雪音乐（lx-music-desktop）📋 音源聚合

**技术栈**：Electron + Vue / React（多版本）

**音源机制**：
- 自定义音源插件（JS脚本）
- 六音音源（`sixyin-music-source-v1.0.7.js`）聚合多平台
- 在线导入：`https://ghproxy.net/https://raw.githubusercontent.com/pdone/lx-music-source/main/flower/latest.js`

**与米豆项目的关联**：落雪的自定义音源脚本机制可能是米豆想要的"插件化音源"模板。

---

### 2.5 Listen1（listen1/listen1_chrome_extension）📋 聚合平台

**支持平台**：网易云、QQ、酷狗、酷我、B站、咪咕、千千（虾米已死）

**关键技术**：**自动切换播放源**（V2.9.0+）——当某首歌在一个平台播放失败，自动从其他平台找可用地址。

**局限**：
- QQ音乐部分收到 DMCA Takedown Notice（部分 fork 关闭）
- 本质是前端聚合，非独立音源接口

## 三、关键结论与路径分析

### 结论1：酷狗必须做完整账号体系

酷狗播放地址的版权校验在服务端——**不管用什么签名，没有登录token就拿不到可用地址**。这意味着：

```
选项A：自己实现扫码登录（复杂度高，约300行RSA+AES加密）
选项B：参考 EchoMusic，直接做概念版账号客户端
选项C：放弃酷狗，转投已有完整登录方案的开源项目
```

### 结论2：EchoMusic 是最佳参考项目

| 维度 | EchoMusic | midou-music-v2 当前 |
|------|-----------|---------------------|
| 桌面框架 | Electron | Tauri v2 |
| 前端 | Vue3 | React |
| 音频引擎 | FFmpeg + SoundTouch (Rust NAPI) | rodio |
| 账号体系 | 扫码+密码+手机（完整） | ❌ 无 |
| 插件系统 | 有（JS插件） | ❌ 无 |
| 实时频谱 | 有（FFT） | ❌ 无 |
| 主题 | 深浅模式+自定义主题色 | 建设中 |

**EchoMusic 的插件机制值得移植**——它用 `ctx.musicSources.register()` 注册音源，这和 midou-music-v2 的 `PlatformPlugin` trait 思路一致。

### 结论3：两条可行路径

#### 路径1：参考 EchoMusic 重构（Tauri 版概念版客户端）

- 登录：实现酷狗扫码/密码登录（比想象中复杂）
- 播放：获取token后走官方 `/v5/url`
- 优点：歌曲库完整、VIP权限自动获取
- 缺点：**登录那块工作量大**，且可能因官方接口变动而失效

#### 路径2：参考落雪音乐的音源聚合方案

- 技术上用**自定义音源脚本**（JS/JSON）定义各平台接口
- 可以直接"借用"落雪社区的音源脚本（六音音源等）
- 酷狗部分：使用落雪已封装好的接口（他们踩过坑）
- 优点：省去登录研发，快速接入
- 缺点：依赖第三方脚本维护状态

#### 路径3：两条腿走路（推荐）

```
Phase 1：先上线酷我（已验证可用）
Phase 2：接入落雪音源脚本（覆盖酷狗/QQ等）
Phase 3：参考 EchoMusic 插件机制建立自己的音源框架
Phase 4：视需要实现酷狗完整登录（如果用户强烈需要VIP音质）
```

## 四、立即可用的音源接口（已验证）

### 酷我（Kuwo）✅ 稳定
- 搜索：`https://mobi.kuwo.cn/mobi.s`（mobi 接口）
- 播放：同接口返回的 play_url
- 状态：**95% 稳定，零Cookie，零登录**

### 酷狗（Kugou）⚠️ 仅搜索可用
- 搜索：`songsearch.kugou.com/song_search_v2`（可用）
- 播放：`/v5/url` / `/yy/index.php`（版权限制）

### 网易云 + UnblockNeteaseMusic（YesPlayMusic 方案）⭐ 新选项
- YesPlayMusic 基于网易云API + UnblockNeteaseMusic 自动替换变灰歌曲
- 扫码登录支持
- 可以给 midou-music-v2 提供一个"网易云"音源
